One original line roasting a gadget used every day: earbuds that drop out for a call and come back just in time to play music to the whole bus. The program writes the line to `/output/entry.txt` (UTF-8, 113 of the allowed 200 characters, single line, deterministic across runs).

## Run it

```sh
python3 main.py
```
